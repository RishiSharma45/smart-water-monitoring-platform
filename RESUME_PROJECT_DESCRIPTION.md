# Resume Project Description

## Short Version

Built a production-ready Smart Water Monitoring Platform using React, Node.js microservices, PostgreSQL, Docker, Kubernetes, Jenkins, Prometheus, Grafana, Loki, and Promtail. Implemented tank monitoring, low-water alerts, CI/CD, observability, centralized logging, Kubernetes autoscaling, and rollback automation.

## Detailed Version

Designed and implemented a cloud-native Smart Water Monitoring Platform with a React frontend and Node.js microservices for user management, tank operations, and notification handling. Integrated PostgreSQL for persistence, Docker Compose for local deployment, Kubernetes for production deployment, Prometheus and Grafana for monitoring, Loki and Promtail for centralized logging, and Jenkins for CI/CD. Added health checks, readiness/liveness probes, resource requests and limits, HPA, PVC, Ingress, Docker Hub image publishing, GitHub webhook support, Slack notifications, and automatic rollback on deployment failure.

## Resume Bullet Points

- Built a full-stack Smart Water Monitoring Platform using React, Node.js, Express, and PostgreSQL.
- Designed microservices for user, tank, and notification domains with service-to-service alert workflow.
- Containerized frontend and backend services using Docker and Docker Compose.
- Deployed services to Kubernetes with ConfigMaps, Secrets, PVC, probes, resource limits, HPA, and Ingress.
- Implemented Prometheus metrics and Grafana dashboards for API, service health, PostgreSQL, and infrastructure monitoring.
- Integrated Loki and Promtail for centralized log collection and Grafana log visualization.
- Created Jenkins CI/CD pipeline with Docker Hub image publishing, Kubernetes rollout verification, Slack notification, and rollback on failure.
